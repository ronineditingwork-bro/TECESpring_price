# TECEspring — прайс и КП (Android и iPhone)

Приложение для продавцов. Внутри каталог TECEspring из розничного прайса TECE на 11/2026, вкладка «ТЕСЕspring сантехника». Цены с НДС 22%, курс 1 EUR = 90 ₽.

- Сделано под Samsung Galaxy Z Fold 7. На сложенном телефоне один экран. На разложенном две колонки: слева каталог, справа карточка товара или корзина. При складывании и раскладывании приложение не перезапускается.
- Каталог по разделам, поиск по названию и артикулу, фильтр «Только в наличии».
- Остатки по каждому товару. В корзине предупреждение, если в КП больше, чем есть на складе.
- Карточка товара с фото, описанием, комплектацией и PDF-инструкциями. Данные взяты с spring.tececatalog.ru.
- Корзина и коммерческое предложение. Кнопка «Печать / PDF» открывает системное окно печати, там можно выбрать «Сохранить как PDF».
- Каталог и фото лежат внутри приложения, поэтому оно работает без интернета. Интернет нужен только для PDF-инструкций.

## Установка

Сначала один раз включите публикацию: Settings → Pages → Source: **GitHub Actions**. После этого приложение пересобирается при каждом push в `main`.

**Android.** Откройте на телефоне https://ronineditingwork-bro.github.io/TECESpring_price/TECEspring.apk и разрешите установку из этого источника. Новая версия ставится поверх старой, корзина сохраняется. APK также лежит в Actions, в артефакте `TECEspring-apk`.

**iPhone.** Откройте в Safari https://ronineditingwork-bro.github.io/TECESpring_price/, нажмите «Поделиться», затем «На экран Домой». Приложение откроется с отдельной иконкой и без адресной строки.

## Как устроено

- `www/` — интерфейс, общий для обеих версий: `index.html`, `app.js`, `styles.css`, прайс `price.js`, остатки `stock.js`, карточки `catalog.js`, фото `img/`.
- `app/` — Android-обёртка (WebView). Она берёт файлы из `www/` и печатает КП через системное окно печати. Ссылки на сайт TECE и PDF открываются в браузере.
- `.github/workflows/pages.yml` собирает APK и публикует `www/` вместе с APK на GitHub Pages.

## Обновление прайса и карточек

Нужны Python 3 и openpyxl (`pip install openpyxl`).

```bash
python scripts/import_price.py "C:\Claude HP\TeceSpring\прайс.xlsx"
```

```bash
python scripts/import_stock.py "путь\к\остаткам.xlsx"
```

```bash
python scripts/scrape_catalog.py
```

Первая команда перезаписывает `www/price.js`. Она берёт только вкладку «ТЕСЕspring сантехника» и останавливается с ошибкой, если в прайсе поменялись колонки или если рубли не равны евро × курс.

Вторая команда перезаписывает `www/stock.js` из выгрузки остатков с колонками «Артикул» и «Доступно». Дату остатков она берёт из свойств файла. В приложение попадают только артикулы из прайса, а тех, которых нет в выгрузке, приложение показывает как «нет в наличии».

Третья команда обходит spring.tececatalog.ru и сопоставляет товары с прайсом по артикулу. Она пишет `www/catalog.js` и скачивает фото, которых ещё нет. В конце печатает артикулы, для которых на сайте нет карточки.

После этого сделайте commit и push, и обе версии обновятся.

## Проверка

```bash
node tests/check.cjs
```

Нужен Playwright с Chromium. Тест проверяет поиск, раскладку для разложенного и сложенного Fold, остатки и фильтр по наличию, карточку товара, кнопку «Назад», корзину и итог, сохранение корзины, ширину экрана телефона, вид для печати и то, что все фото открываются.
