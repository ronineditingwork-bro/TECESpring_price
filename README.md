# TECEspring — прайс и расчёт

Каталог TECEspring из розничного прайса TECE на 11/2026, вкладка «ТЕСЕspring сантехника». Цены с НДС 22%, курс 1 EUR = 90 ₽. В каталоге 7 разделов и 108 позиций.

- Поиск по названию и артикулу, фильтр по разделу.
- Корзина с количеством и итоговой суммой. Хранится в браузере.
- Коммерческое предложение: кнопка «Печать / PDF» печатает только таблицу КП. В окне печати можно выбрать «Сохранить как PDF».

Сайт статический, без сервера и сборки. Чтобы открыть, достаточно запустить `index.html` двойным щелчком. Подходит для GitHub Pages (Settings → Pages → ветка `main`) и для любого хостинга статических файлов.

## Обновление прайса

Нужны Python 3 и openpyxl (`pip install openpyxl`).

```bash
python scripts/import_price.py "C:\Claude HP\TeceSpring\прайс.xlsx"
```

Скрипт перезаписывает `price.js`. Он останавливается с ошибкой, если в прайсе поменялись колонки или если цена в рублях не равна цене в евро, умноженной на курс. Повторяющиеся артикулы скрипт пропускает. Позиции, которых нет в новом прайсе, удаляются из корзины при открытии страницы.

## Проверка

```bash
node tests/check.cjs
```

Нужен Playwright с Chromium. Тест проверяет поиск, корзину, итог, сохранение корзины после перезагрузки, отсутствие горизонтальной прокрутки на телефоне и вид для печати.
