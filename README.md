# TECEspring — прайс и КП (Android и iPhone)

Приложение для продавцов. Внутри все вкладки розничного прайса TECE: «Трубопроводы ТЕСЕ», «Сантехника ТЕСЕ», «ТЕСЕspring AX», «ТЕСЕspring сантехника», Uranum, BWT, Poloplast, Conex Banninger и Viega, всего 3154 позиции. Цены с НДС 22%, в рублях, как в прайсе.

- Сделано под Samsung Galaxy Z Fold 7. На сложенном телефоне один экран. На разложенном две колонки: слева каталог, справа карточка товара или корзина. При складывании и раскладывании приложение не перезапускается.
- На главном экране разделы, по одному на вкладку прайса. Внутри раздела группы и подгруппы в том же порядке, что в прайсе. Поиск по названию и артикулу ищет по всем разделам. Есть фильтр «Только в наличии».
- Остатки по двум складам, Ростов-на-Дону и Москва, у каждого товара. В корзине предупреждение, если в КП больше, чем есть на складе.
- Карточка товара с фото, описанием, комплектацией и PDF-инструкциями. Для TECEspring данные взяты с spring.tececatalog.ru.
- Корзина, из которой делаются «Коммерческое предложение» и «Счёт на оплату» в виде заводской проформы. В шапке марка и продавец, рядом номер, дата и срок, ниже поставщик и покупатель, таблица позиций с фото и артикулами, разбивка «без НДС / НДС / итого», сумма прописью. В счёте внизу ещё платёжные реквизиты. Продавец выбирается из общего списка организаций, как в WHITECROSS и MAPEI (ИП Ненашев, ИП Плешков, ООО «АМАНА ГРУПП», ООО «КЕРБЕР-ЮГ»). На Android PDF сохраняется в «Загрузки/TECEspring», после чего сразу открывается окно «Отправить». На iPhone документ открывается с кнопкой «Сохранить PDF / Поделиться».
- Кнопка «Назад» в шапке на всех внутренних экранах. Она возвращает на предыдущий экран: из карточки в раздел, из раздела на главный экран, из документа в корзину. Системная кнопка «Назад» на Android работает так же.
- Плавные переходы между экранами: фото товара «перетекает» из плитки каталога в карточку. Если в настройках телефона уменьшено движение, переходы отключаются.
- Каталог и фото лежат внутри приложения, поэтому оно работает без интернета. Интернет нужен только для PDF-инструкций.

## Установка

Сначала один раз включите публикацию: Settings → Pages → Source: **GitHub Actions**. После этого приложение пересобирается при каждом push в `main`.

**Android.** Откройте на телефоне https://ronineditingwork-bro.github.io/TECESpring_price/TECEspring.apk и разрешите установку из этого источника. Новая версия ставится поверх старой, корзина сохраняется. APK также лежит в Actions, в артефакте `TECEspring-apk`.

**iPhone.** Откройте в Safari https://ronineditingwork-bro.github.io/TECESpring_price/, нажмите «Поделиться», затем «На экран Домой». Приложение откроется с отдельной иконкой и без адресной строки.

## Как устроено

- `www/` — интерфейс, общий для обеих версий: `index.html`, `app.js`, `styles.css`, шрифт Golos Text `fonts/`, прайс `price.js`, остатки `stock.js`, реквизиты продавцов `sellers.js` (тот же файл, что в WHITECROSS и MAPEI), документы `docs.js` и `doc.html`, карточки `catalog.js`, фото `img/`.
- `app/` — Android-обёртка (WebView). Она берёт файлы из `www/` и сохраняет КП и счета в PDF. Ссылки на сайт TECE и PDF открываются в браузере.
- `.github/workflows/pages.yml` собирает APK и публикует `www/` вместе с APK на GitHub Pages.

## Обновление прайса и карточек

Нужны Python 3 и openpyxl (`pip install openpyxl`).

```bash
python scripts/import_price.py "C:\Claude HP\TeceSpring\прайс.xlsx"
```

```bash
python scripts/import_stock.py Ростов-на-Дону "путь\к\остаткам.xlsx"
```

```bash
python scripts/import_stock.py Москва "путь\к\2026.11.25 Остатки ОБЕРОН.xlsx"
```

```bash
python scripts/scrape_catalog.py
```

```bash
python scripts/scrape_tilda.py https://uranum-russia.ru Uranum
```

Команда для прайса перезаписывает `www/price.js` из всех вкладок. Строки без артикула становятся группами: на вкладках с нумерованными заголовками («1. TECEflex») группа — нумерованный заголовок, заголовки под ним — подгруппы. Цена берётся из колонки «РРЦ, РУБ.» как есть. Повтор артикула пропускается, а если у повтора другая цена, команда об этом печатает.

Команды для остатков обновляют в `www/stock.js` только указанный склад. Они читают все листы выгрузки, где есть колонки «Артикул» и «Доступно» или «Текущие остатки». Дату остатков скрипт берёт из свойств файла, а если её там нет — из даты изменения файла. В приложение попадают только артикулы из прайса, а артикулы, которых нет в выгрузке, считаются отсутствующими на этом складе.

`scrape_tilda.py` берёт фото с сайта на Tilda для одной вкладки прайса: ищет артикулы на страницах сайта и скачивает фото найденной страницы, уменьшенные до 700 px. Уже найденные фото он не трогает.

`scrape_catalog.py` обходит spring.tececatalog.ru и сопоставляет товары с прайсом по артикулу. Она пишет `www/catalog.js` и скачивает фото, которых ещё нет. В конце печатает артикулы, для которых на сайте нет карточки.

После этого сделайте commit и push, и обе версии обновятся.

## Проверка

```bash
node tests/check.cjs
```

```bash
node --test tests/docs.test.js
```

Нужен Playwright с Chromium. Первый тест проверяет поиск, КП и счёт с фото и реквизитами выбранного продавца, раскладку для разложенного и сложенного Fold, остатки и фильтр по наличию, карточку товара, кнопку «Назад», корзину и итог, сохранение корзины, ширину экрана телефона, вид для печати и то, что все фото открываются.
